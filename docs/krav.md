# Krav

Kraven bor i GitHub Issues. Den här sidan pekar dit så att dokument och issues hänger ihop.

| Vy | Länk |
|---|---|
| Epics | [typ:epic](https://github.com/JoseMdS/altvault/issues?q=is%3Aissue+label%3Atyp%3Aepic) |
| Öppna krav | [typ:krav, öppna](https://github.com/JoseMdS/altvault/issues?q=is%3Aissue+is%3Aopen+label%3Atyp%3Akrav) |
| Alla krav | [typ:krav](https://github.com/JoseMdS/altvault/issues?q=is%3Aissue+label%3Atyp%3Akrav) |
| User stories | [typ:story](https://github.com/JoseMdS/altvault/issues?q=is%3Aissue+label%3Atyp%3Astory) |
| Baslinje (levererat) | [baslinje](https://github.com/JoseMdS/altvault/issues?q=is%3Aissue+label%3Abaslinje) |

ID-format: `AV-EPIC-NN`, `AV-KRAV-NNN`, `AV-US-NNN`. Se [ID-schema](https://josemds.github.io/dev-portal/arbetssatt/id-schema/).
